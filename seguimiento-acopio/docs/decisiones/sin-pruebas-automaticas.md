# Sin pruebas automáticas por ahora

## Contexto

Es un proyecto chico en evolución rápida, con una sola persona, y se prueba a mano en local y en el Preview de Vercel.

## Decisión

No se agregan pruebas automáticas por ahora.

## Consecuencias

- Cada etapa se cierra con typecheck, build y una prueba manual de los flujos afectados.
- Es una decisión a revisar cuando el código se estabilice o se sumen más personas.
