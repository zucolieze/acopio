# Sin cambios en el modelo de datos

## Contexto

El refactor es de organización y de nombres; mezclarlo con entidades nuevas lo haría riesgoso.

## Decisión

No se agregan entidades nuevas (planta, organización, etc.). Las vistas de lectura no cambian el modelo.

## Consecuencias

- Las novedades de producto se hacen aparte, fuera de las etapas del refactor.
